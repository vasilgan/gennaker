# COLREG Trainer MVP

Прототип React-приложения для тренировки правил расхождения судов с короткими сессиями и интервальными повторами.

## Запуск

```bash
npm install
npm run dev
```

Тесты:

```bash
npm run test
```

## Что реализовано

- 3 экрана: Home, Training, Progress.
- Training всегда формирует сессию из 5 вопросов.
- Локальный банк вопросов (versioned) на 4 модуля, 20 вопросов суммарно.
- Полный цикл: ответ → разбор → планирование следующего показа (`dueAt`) → переход в прогресс или запуск новой 5-минутной тренировки прямо с финала сессии.
- Хранение прогресса в `localStorage` (без backend).
- XP и бейдж `Coastal Ready`.

## Структура

- `src/data/` — типы и банк вопросов.
- `src/domain/` — бизнес-логика (выбор сессии, интервалы, confidence, бейджи).
- `src/storage/` — интерфейс и адаптер localStorage.
- `src/ui/` — страницы и компоненты.

## Правила интервального повторения

Для каждого вопроса сохраняются: `attempts`, `wrong`, `streakCorrect`, `dueAt`, `lastAnsweredAt`, `lastResult`.

При ответе:

- `attempts += 1`, `lastAnsweredAt = now`
- Верно:
  - `streakCorrect += 1`
  - `lastResult = "correct"`
  - если `streakCorrect >= 3` → `dueAt = now + 14 days`
  - иначе → `dueAt = now + 3 days`
- Неверно:
  - `streakCorrect = 0`
  - `wrong += 1`
  - `lastResult = "wrong"`
  - если прошлый результат тоже `wrong` → `dueAt = now + 8 hours`
  - иначе → `dueAt = now + 24 hours`
- Важно: проверка "две ошибки подряд" выполняется по `lastResult` **до** его обновления в текущем ответе.

## Алгоритм выбора 5 вопросов

1. Сначала `dueAt <= now` (самые просроченные первыми).
2. Если < 5: добираем новыми вопросами (без прогресса), стараясь покрыть разные модули.
   - Новый вопрос считается "новым", если в `userState.questionProgress` отсутствует запись по `questionId`.
3. Если всё ещё < 5: добираем ближайшими upcoming (минимальный `dueAt`).
4. Дубли одного и того же вопроса в сессии запрещены.

## Confidence и Progress

По каждому модулю:

- `qScore = attempts == 0 ? null : max(0, 1 - wrong / attempts)`
- confidence = среднее по `qScore` среди отвеченных вопросов, в процентах 0–100.
- Если в модуле нет отвеченных вопросов, confidence = "недостаточно данных"; такой модуль не проходит проверку бейджа.
- показывается число вопросов "на сегодня" (`dueAt <= now`).

## Геймификация

- XP: `+10` за верный, `+2` за неверный.
- Badge `Coastal Ready` выдается если:
  - confidence >= 75% по всем 4 модулям,
  - и в каждом модуле минимум 5 попыток суммарно.

## Как добавить вопросы

1. Откройте `src/data/questions.ts`.
2. Добавьте объект в `QUESTIONS`:
   - `id`, `moduleId`, `prompt`
   - `choices` (3–4 варианта)
   - `correctChoiceId`
   - `explanation: { ruleRefs, why, commonMistake?, realWorldAction? }`
   - опционально `media` в виде inline SVG.
3. При изменении банка увеличьте `QUESTION_BANK_VERSION`.

## Принятое допущение

Для MVP после 5-го вопроса показаны явные действия: `Новая тренировка (5 мин)` и `Перейти в прогресс` для замыкания учебного цикла без скрытой автоматики.
